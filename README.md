# Codenotch 日本語版

AI コーディングアシスタントの使用量と作業状態を、Mac の画面端に小さなノッチとして表示するアプリです。

[vinzdg/codenotch](https://github.com/vinzdg/codenotch) v1.5.0 をベースにした非公式の日本語フォークです。原作のデザイン・開発は [@hivinz_](https://x.com/hivinz_)。原作の説明は [README.en.md](README.en.md) を参照してください。

## 日本語版の変更点

- 設定、メニュー、ツールチップ、連携方法、使用量、作業状態、新機能の案内を日本語化。
- リセット日時を日本語・24時間表記に変更。タイムゾーンは Mac の設定を使用します。
- 本家と区別するため、アプリ識別子を `com.zenon7171.codenotch` に変更。
- 本家の自動更新で日本語版が上書きされないよう、自動更新を無効化。設定から[日本語版の配布ページ](https://github.com/zenon7171/codenotch/releases)を開けます。

サービス名、モデル名、ユーザーが付けたセッション名、サーバーや macOS が返すメッセージは元の表記で表示される場合があります。開発用の設計資料・過去の変更履歴は原文を保持しています。

## 対応サービス

| サービス | 使用量の取得元 |
|---|---|
| Claude Code | ログインキーチェーンの OAuth 情報と Claude Code の使用量エンドポイント |
| Cursor | エディタのローカル SQLite に保存されたサインイン情報 |
| Codex | ローカルの Codex 認証情報と ChatGPT の使用量エンドポイント |
| Antigravity | ローカル言語サーバー、または Google の使用量情報。取得できない場合はリクエスト数 |
| GLM | Claude Code、ZCode、OpenCode に設定された Z.ai Coding Plan のキー |
| Grok | `~/.grok/auth.json` とクレジット使用量のエンドポイント |
| OpenCode | OpenCode に保存された `opencode-go` キーと Go プランの使用量エンドポイント |

Codenotch 自体に各サービスのパスワードを入力する必要はありません。連携元のツールをインストールしてサインインすると、その認証情報を使って取得します。Claude は Claude アプリではなく **Claude Code** が対象です。

Claude Code の複数アカウントにも対応します。たとえば `CLAUDE_CONFIG_DIR=~/.claude-work claude` で使うアカウントは、個人用とは別のリングになります。

## 使い方

1. 対応するツールでサインインしてから Codenotch を起動します。
2. 画面端のノッチにポインタを重ねると、各サービスのリングが表示されます。
3. リングにポインタを重ねると、使用済みの割合、残量、リセット日時、実行中のセッションを確認できます。
4. ノッチの歯車から設定を開き、連携サービス、配置、表示方法を変更できます。右クリックの「今すぐ更新」で再取得できます。

リング内の動く弧は作業中、点滅する黄色のリングはユーザーの応答待ちを示します。画面の上下左右に配置でき、Dock や Mac 本体のノッチを考慮して表示されます。

連携をオフにすると、その認証情報の読み取りを停止し、保存した使用量を削除します。連携元のツールからはサインアウトしません。

## ビルド

**macOS 26 以降、Xcode 26 以降、XcodeGen** が必要です。

```sh
brew install xcodegen
git clone https://github.com/zenon7171/codenotch.git
cd codenotch
make build
make test
make run
```

日本語版はローカルビルド向けのアドホック署名を使用します。Apple の Developer ID による署名・公証済みの配布版ではありません。再ビルドで署名が変わるとキーチェーンへのアクセス確認が再表示される場合があります。

認証情報を使わずに固定データで確認する場合は、ビルドした実行ファイルを `CODENOTCH_DEMO=1` を付けて起動してください。

本家の `make release` は本家の証明書・公証プロファイル・配布先を前提とするため、このフォークでは使用しないでください。独自の署名済み配布と更新フィードは未設定です。

## データ取得について

各アダプターは連携元の内部エンドポイントやローカルデータを使用します。サービス側の変更で取得できなくなる可能性があります。取得失敗時には状態や最後の取得値を表示し、使用量を推測して補うことはありません。

キーチェーンへのアクセスを macOS が求めた場合、「常に許可」を選ぶと同じ署名のアプリからの再確認を抑えられます。許可を拒否した場合は、設定の「アクセスを許可…」から再試行できます。
