# 四隅の配置（日本語版1.5.1）

右上・右下・左上・左下を追加。既存の上下左右と合わせて8か所を設定の「配置」メニューから選べます。四隅では左右の縦型形状を使用し、パネルを画面の使用可能領域の端に配置します。上中央以外は本体のカメラノッチと結合しません。

## 確認

- 562件のテスト成功。
- 四隅の原点と画面境界、別ディスプレイの負の座標、Dock・メニューバーの除外を検証。
- 四隅での形状・ツールチップの向き・座標変換が対応する左右と一致することを検証。
- 8方向すべての設定保存・復元を検証。
- 四隅ではセッション数の計算に画面の使用可能な高さを使うことを実装。使用可能高さ960pt・7サービスでパネルが収まることを検証。
- `/Applications/Codenotch 日本語版.app` の1.5.1を起動し、新機能案内と8方向の設定を確認。実画面で「右上」の選択を確認した。操作中にユーザーが右上を選択したため、その設定を維持。
- 開発ビルドは `build/DerivedData.noindex` に保存し、アプリ検索の重複を防ぐ。

## build 9 で修正した配置の不具合

build 8 は透明なツールチップ用の余白を含むパネルを角に寄せていました。このため、設定の選択は反映されてもノッチ本体は角から大きく離れていました。ユーザーのスクリーンショットで判明した、初回検証の不足です。

build 9 はノッチ本体と設定ハンドルを基準に角へ配置し、ツールチップを画面内で独立して移動させます。吹き出しの先端とマウス判定も同じ位置に合わせています。折りたたんだノッチも角に残ります。

- 2サービスのノッチ本体が上側の角に余白なしで接する回帰テストを追加。
- 下側では設定ハンドル分だけを確保し、本体とハンドルの末端がパネル下端に一致することを検証。
- 折りたたみ時の角への固定、カードの見切れ防止、吹き出しの先端とリングの一致を検証。
- インストール済みアプリをbuild 9に更新して起動し、実画面で本体がパネル右上端に接し、大きな上余白が消えたことを確認。

自動更新は変更していません。[日本語版の更新構成案](japanese-updates.md)を参照してください。
