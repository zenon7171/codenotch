検証対象は `build/japanese/Codenotch.app`。識別子は `com.zenon7171.codenotch`。最終テストで生成されたアプリと、実画面確認・納品に使ったアプリの `Codenotch.debug.dylib` の SHA-256 が一致しています。

```
4d988e7a076004353cbf5a11710b7dfb0ae61050e62b3480708652e2df663b05
```

`codesign --verify --deep --strict` に成功しました。これはアドホック署名の整合性確認であり、Apple の公証や Developer ID 配布の検証ではありません。

## 修正した問題

- Cursor の計測対象がない場合の案内が英語だったため日本語化。プラン名がない場合の `this` も修正。
- Cursor の応答待ち理由 `needs your input` を日本語化。
- Claude の追加プロファイルの取得元表記、Antigravity の個人用アカウント表記を修正。
- 通信失敗などで OS の英語メッセージがそのまま表示される経路を、日本語の案内と診断用コードに変更。元のエラーはログに保持。
- 設定表示が同期的にキーチェーンを読み、UI のメインスレッドが止まっていた。プロセスのスタック取得で `SettingsView → providerSummaries → account → SecItemCopyMatching` を確認。設定用の読み取りをバックグラウンドに移し、確認中の表示を追加。
- ⌘, が SwiftUI の空の Settings シーンを開いていた。通常の設定ウィンドウを開くコマンドに接続。
- 新機能画面の装飾アイコンから内部名 `AppIcon` を読み上げないように修正。

## 翻訳の確認範囲と残る原文

ただし、画面に英語が一切出ないという意味ではありません。次は原文を保持します。

- サービス名、モデル名、プランの商品名、プロファイル名、ユーザーのセッション名・作業内容。
- サービスが返す任意のラベル・待機理由など。未知の内容を推測して翻訳しません。
- macOS の「サービス」メニューに他アプリが登録した項目。実機では Instruments 関連の英語項目を確認しました。
- URL、コマンド、エラーの診断識別子、コード・ログ、ライセンス、原文ドキュメント、既存のWebサイト資料。
